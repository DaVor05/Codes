Cómo escribir una historia

  1. Idear una premisa o conflicto central.
  2. Desarrollar a los personajes principales y secundarios.
    • Definir sus motivaciones.
    • Elegir sus nombres y rasgos físicos.
    • Crear un trasfondo para cada personaje.
  3. Escribir el primer borrador sin detenerse.
  4. Revisar y editar el borrador para mejorar la trama y los personajes.
  5. Publicar o compartir la historia con otros para saber si les gusta.
